# Security Code Rules

- 비밀키, 토큰, 비밀번호와 실제 개인정보를 코드, 테스트 데이터와 로그에 저장하지 않습니다.
- 인증 성공과 업무 권한 보유를 별도로 검증합니다.
- 조회·수정 대상에 대한 사용자 또는 조직 범위를 서버에서 검증합니다.
- 문자열 결합으로 SQL, 명령어와 동적 경로를 만들지 않고 안전한 바인딩 방식을 사용합니다.
- 파일 업로드는 크기, 형식, 이름, 저장 경로와 악성 콘텐츠 위험을 검증합니다.
- 외부 URL 호출은 허용 대상, Redirect, Timeout과 내부망 접근 위험을 검토합니다.
- 로그에는 필요한 추적 정보만 남기고 민감한 요청·응답 본문을 기본 기록하지 않습니다.
- 보안 관련 실패는 안전한 기본값으로 종료하며 우회 동작을 만들지 않습니다.
- 새로운 외부 의존성과 GitHub Action은 출처, 권한과 공급망 위험을 검토합니다.
