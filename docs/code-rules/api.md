# API Code Rules

- API 경로, 요청, 응답과 오류 형식은 구현 전에 계약으로 명확히 합니다.
- 입력 형식, 필수 값, 범위와 상호 조건을 시스템 경계에서 검증합니다.
- 인증 여부와 권한 검사를 분리해서 누락을 확인합니다.
- 같은 오류는 일관된 상태 코드와 오류 코드로 응답합니다.
- 내부 예외, SQL, 스택 트레이스와 비밀정보를 응답에 노출하지 않습니다.
- 상태 변경 API는 재시도, 중복 요청과 멱등성 필요 여부를 검토합니다.
- 목록 API는 데이터 증가를 고려해 페이지 처리와 정렬 기준을 명시합니다.
- 공개 계약을 깨는 변경은 버전 또는 호환 전략 없이 적용하지 않습니다.
- Controller 테스트와 업무 로직 테스트의 책임을 구분합니다.
- 요청·응답 변환은 [DTO 규칙](dto.md)을 따릅니다.
- 예외의 HTTP 변환은 [예외 규칙](exception.md)을 따릅니다.
